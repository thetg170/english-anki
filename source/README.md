# Source data

`pilot/notes.csv` and `english-grammar/notes.csv` are the canonical, Git-tracked note content. Their `.schema.json` files define fields and note types. `english-grammar/notetype.json` preserves templates and CSS. The older JSON/JSONL files remain as initial snapshots, but package builders now read CSV. A simple scan found no email addresses, URLs, phone numbers, or common API key patterns in the grammar fields; review content and licensing before publishing this repository. The full collection, review history, and media remain under ignored `private/` and require a separate secure backup.

The exact deck name in the collection on 2026-11-04 is `English Grammar`. It is not renamed to the requested spelling `English Gramar`.
