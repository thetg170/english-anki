# 13. Bị động: tập trung vào việc và kết quả

**Học trước:** [Quá khứ đơn](02-past-simple.md), [kế hoạch tương lai](03-future.md). **Học tiếp:** [Work](23-work.md).

## Learning Objectives

Nói việc đã/đang/sẽ được làm khi người thực hiện không quan trọng hoặc chưa biết; vẫn giữ đúng thì.

## Core Concepts

Câu chủ động chú ý **ai làm**: “Mai sent the report.” Bị động đưa **đối tượng nhận hành động** lên trước: “The report was sent.” Công thức cốt lõi là **be + V3**; *be* mang thì, còn V3 giữ nguyên. Chỉ thêm *by Mai* nếu thông tin người làm thật sự có ích. Không phải mọi câu có *be + V3* đều cần dịch cứng thành “được/bị”.

## Sentence Structures

| Thời/thể | Ghép câu |
|---|---|
| Hiện tại đơn | subject + am/is/are + V3 |
| Quá khứ đơn | subject + was/were + V3 |
| Tương lai | subject + will be + V3 |
| Hiện tại hoàn thành | subject + have/has been + V3 |
| Đang diễn ra | subject + am/is/are being + V3 |

## Usage

“The meeting was moved to Thursday” tự nhiên khi quan tâm lịch mới. “The server is being repaired” nói việc đang diễn ra. Nếu cần giao trách nhiệm rõ ràng, chủ động thường trực tiếp hơn: “Mai will send the file.”

## Examples

| English | Nghĩa |
|---|---|
| The room is cleaned every day. | Phòng được dọn mỗi ngày. |
| My laptop was stolen yesterday. | Laptop của tôi bị lấy trộm hôm qua. |
| The report will be sent tomorrow. | Báo cáo sẽ được gửi ngày mai. |
| The server is being repaired now. | Máy chủ đang được sửa. |

## Common Mistakes

- ❌ “The report sent yesterday” khi không nêu người gửi → ✅ “The report was sent yesterday.” Thiếu *be*.
- ❌ “It was send” → ✅ “It was sent.” Cần V3.
- ❌ “The server is repairing” nếu máy chủ là đối tượng được sửa → ✅ “The server is being repaired.”

## Sentence Building

1. Chủ động: **Someone moved the meeting.**
2. Chuyển trọng tâm: **The meeting was moved.**
3. Thêm kết quả hữu ích: **The meeting was moved to Thursday.** Không cần *by someone*.

## Variations

Đổi thì: “The file is sent every Monday” / “was sent yesterday” / “will be sent tomorrow”. Phủ định: “The file wasn't sent.” Hỏi: “Was the file sent?”. Chọn chủ động nếu muốn nói người chịu trách nhiệm.

## Real-life Situations

**A:** Why can't I use this server?  
**B:** It's being repaired right now. It should be ready soon.

## Practice

1. Nói cuộc họp đã được dời sang thứ Năm.
2. Đổi “Someone will send the report tomorrow” sang bị động.

**Đáp án tham khảo:** 1. “The meeting was moved to Thursday.” *Was* mang thì quá khứ. 2. “The report will be sent tomorrow.” *Will be + V3*; bỏ *by someone* vì không thêm thông tin.

## Tra cứu và mở rộng

Tra [bảng động từ bất quy tắc](../reference/irregular-verbs.md) để lấy V3 sau *be*; thay đổi thì ở *be*, không đổi V3.

### Must Know: giữ thì trên *be*

| Chủ động → bị động | Ví dụ / nghĩa | Điểm cần nhìn |
|---|---|---|
| sends → is sent | The file is sent every Monday. — File được gửi mỗi thứ Hai. | Thói quen hiện tại. |
| sent → was sent | The file was sent yesterday. — File được gửi hôm qua. | Việc đã xong. |
| will send → will be sent | The file will be sent tomorrow. — File sẽ được gửi mai. | Tương lai. |
| has sent → has been sent | The file has been sent. — File đã được gửi rồi. | Kết quả hiện tại. |
| is repairing → is being repaired | The server is being repaired. — Máy chủ đang được sửa. | Đang diễn ra. |

### Good to Know / Special Cases

Sau modal: *must/can/should + be + V3*: “It must be checked” (Nó phải được kiểm tra). Với động từ hai tân ngữ, có thể đưa người nhận lên trước: “They sent me a file” → “I was sent a file”; nhưng “A file was sent to me” thường dễ hiểu hơn. *Get + V3* trong lời nói có thể nhấn sự kiện/xảy đến: “My phone got stolen” (Điện thoại tôi bị lấy trộm); không thay được mọi dạng bị động trang trọng. Tránh bị động nếu muốn người nghe biết **ai chịu trách nhiệm**: “Mai will send the report” rõ hơn “The report will be sent”.

**Tự tạo câu:** Lấy một hành động thật trong công việc, nói chủ động rồi bị động và giải thích vì sao đổi trọng tâm. Mẫu: “The team fixed the bug” → “The bug was fixed yesterday”; sau đó đổi sang “The bug is being fixed” nếu việc vẫn đang diễn ra.
